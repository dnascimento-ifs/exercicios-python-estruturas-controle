# Aula 12 - Condições Aninhadas
Continuação da aula 10, que falou sobre condições simples e compostas, nessa aula foi abordado o seguinte:
```
"O que fazemos quando é necessário escolher entre mais que 2 caminhos diferentes?"
```
Assim iremos trabalhar com o aninhamento (também chamado de encadeamento) de condições no python.
