# Aula 12 — Condições Aninhadas

Nesta aula são estudadas estruturas condicionais com mais de dois caminhos possíveis, utilizando `if`, `elif` e `else`.

## Conceitos estudados

- Condições simples;
- Condições compostas;
- Condições aninhadas ou encadeadas;
- Uso de `if`, `elif` e `else`;
- Operador `in`;
- Operadores lógicos;
- Indentação em Python.

## Arquivo da aula

O conteúdo prático está no notebook:

- `aula-12-condicoes-aninhadas.ipynb`

## Como executar

O notebook pode ser aberto com:

- Jupyter Notebook;
- JupyterLab;
- Google Colab;
- Visual Studio Code com a extensão Python.
